# Добро пожаловать в AppsFlyer!

> **At a glance:** Learn what mobile advertising attribution is and how AppsFlyer helps marketers pinpoint their targeting, optimize their ad spend, and boost ROI. bla.

## Что такое атрибуция приложений?

App attribution **determines which campaigns, partners, and channels drive your app installs** and post-install events, such as in-app purchases. Маркетологи используют эти аналитические данные для измерения и повышения эффективности своих действий в рамках кампаний по привлечению пользователей и ретаргетинговых кампаний.

## Первый вход в систему

При первом создании пользователя по электронной почте приходит приглашение активировать аккаунт. После активации вы можете войти в систему, и аккаунт станет активным. Обратите внимание, что ссылка на активацию действительна в течение 48 часов.

<Image alt="login page.png" src="https://files.readme.io/a55e3d6281c58eea9075a7f8a2b5eb558679d620fc2e66637d7c046afeeaad5a-51073385138705.png" width="322px" />.

Есть несколько способов входа в аккаунт AppsFlyer:

- Использование учетных данных: Email и пароль
- Вход в систему через Google: Вход в систему с помощью аккаунта Google
- <Anchor target="_blank" href="/marketers/docs/set-up-sso-authentication-with-your-identity-provider-idp">Login using SSO</Anchor>

> 📘 **Примечание**
>
> If your administrator configured a two-factor authentication (<Anchor target="_blank" href="/marketers/docs/implementing-and-using-2fa-login">2FA</Anchor>) for your account, you'll be asked to verify the login using another authentication method.

## multiple accounts.png

Users can exist in multiple accounts with different roles and permissions. They can navigate between their accounts without the need to re-enter credentials.

> 📘 **Примечание**
>
> - Switching between accounts and changing the primary account is supported for all login methods: Username and password, 2FA, and Single Sign-On (SSO). Switching also requires a 6-digit verification code sent to the user's email, regardless of login method used.
> - At this stage, switching between accounts is restricted to advertiser accounts only.

### Primary account

The primary account is the initial account that was created and acts as the default login account. Войдя в один аккаунт, вы сможете переключиться на другой.

<Image alt="primary-account1.jpg" src="https://files.readme.io/8f1d88543b4797b584fa781bf2dd2563ed91f6eaff45393b186d8da98ccc0c33-51073397865233.jpg" width="672px" />.

**Для переключения между аккаунтами:**

1. From the menu bar, select the **email address dropdown** > **Switch accounts**.
2. Access the list of your accounts: Select **All accounts (x)**, with x indicating the total number of accounts.
3. In the **My accounts** dialog, click the 3 dots menu icon for the account to be set as primary, then select **Set as primary**. A message confirms the account change.

### Переключение между аккаунтами

1. From the menu bar, select the **email address dropdown** > **Switch accounts**. <Image alt="image (73).png" src="https://files.readme.io/b9aaf81a586da0240bb3813a0ad416ac1cf5badc0f976ddc0156e1bd798036df-51074002494481.png" width="313px" />.
2. Войдите в систему и выберите другой аккаунт из списка связанных аккаунтов. <Image alt="image (74).png" src="https://files.readme.io/7ff19bd9db1b1f72e06b594ce536200cd6139a1882e56e72877200542944d6f8-51074002495505.png" width="75%" />.
3. Enter the 6-digit verification code sent to your email address. <Image alt="image (769).png" src="https://files.readme.io/ccb2c3e8f8724f95e6ec265697b3851efeaf33ff6aabde4599e3d17c57949a44-51074002496017.png" width="75%" />.
4. Нажмите «Сменить аккаунт».<Image alt="image (75).png" src="https://files.readme.io/81e6f17ed80eddcc1d3e55ca9336ed62b82fd1c6694a30a347ba24ae8bed57e4-51074025826705.png" width="75%" />.

> 📘 **Примечание**
>
> The verification code is valid for 15 minutes and can only be used once.
